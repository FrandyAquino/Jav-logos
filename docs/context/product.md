# Product contract

JavLogos is a local-first AI branding studio in JavCollections. A brand family has parent brands, sub-brands and applications. Brand DNA resolves palette, typography, geometry and tone through explicit per-field inheritance; overrides stay distinctive. Existing JavDesign and JavParlance are independent products, not dependencies.

Build an end-to-end desktop path: create/select a brand, edit inherited DNA, describe a concept, generate a batch using a local provider, inspect and vectorize imagery, edit geometric vector compositions, save versions, analyze consistency, and export a portable brand kit. Procedural concepts are a separately labeled offline tool and never represented as model inference.

Privacy: no required login, subscription or network. Optional providers must be explicit. Optional creative integrations remain unavailable until a real API and desktop authorization design are verified.

Terminology: brand = identity node; DNA = inheritable design rules; concept = proposed logo; version = immutable saved concept state; kit = SVG/PNG plus palette, typography and provenance metadata; reference = user-supplied image guiding generation.
