# Offline font outlines and image preparation

Verified2026-11-25 against installed `fontkit`3.0.0 and official upstream documentation: https://github.com/foliojs/fontkit . The package exposes separate browser/Node builds, WOFF2 decoding, variation axes, shaped glyph positions and SVG path extraction. Its MIT license and dependency notices are bundled in `public/licenses/font-engine.txt`. Brotli's package declares MIT; its decoder sources carry Google Apache2.0 notices, included with the full Apache license. Existing font-specific OFL notices remain in their asset directories and exported kits.

The adapter uses only bundled, approved font files. It selects supported glyphs across Unicode subsets, uses variable weight/optical-size axes where available and retains advance/offset/kerning geometry. Missing glyphs or unavailable system-font bytes are explicit errors. No arbitrary filesystem font access or cloud service is added. `fontkit.d.ts` is a narrow adapter declaration for the public APIs actually used and validated; the available DefinitelyTyped package targets2.x and was not installed for3.x.

Real bundled-font tests cover all10 packaged font families, including Spanish accents and monograms. Browser raster checks compare live-text and outlined output for Manrope, Google Sans Flex and Playfair Display; measured bounds differ by under5 output pixels and ink area within10%. This is scoped rendering evidence, not universal script/font/editor certification. Parser code is dynamically loaded only for outlining (380.34KB uncompressed/156.50KB gzip in the verified build).

Flat-background removal uses a bounded local Web Worker, uniform-border detection, connected-region removal, feathering/decontamination and an opt-in enclosed-color removal. It crops empty outer margins with padding and writes a new derived concept. Maximum4MP and4096px per side. This is a deterministic logo cleanup algorithm, not photographic segmentation. Nonuniform backgrounds, erased foreground and unavailable processing fail visibly.
