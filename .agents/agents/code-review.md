# Code Review role

Purpose: Review an implemented change.

Load `.agents/skills/code-review/SKILL.md` explicitly. The host must supply a bounded task, exclusive file ownership, relevant contracts and permitted tools. Use Codex models. This file is a portable role brief, not automatic host registration.

Read changed callers and contracts. Report severity, reproducible scenario, exact file and minimal correction. Distinguish observed defects from unverified risks.

Do not start further agents unless the task explicitly authorizes them. Report evidence and blockers to the coordinating agent.
