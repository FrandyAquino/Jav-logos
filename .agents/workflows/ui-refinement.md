# Refine the studio UI

Read canonical product/design docs and the named reference's actual UI/source. Choose a small compatible skill set; record why each fits. Commit the design contract before parallel edits and assign disjoint CSS, TSX and asset ownership. Preserve data/domain contracts. The coordinator runs integration tests, rendered checks and native inspection, then an independent reviewer checks the result. Fix demonstrated defects, update evidence and commit only owned files. Do not equate polished UI with a production-certified release.
